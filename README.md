# G3 Architects Website

A responsive landing page for an architecture-focused brand built with **HTML5** and **CSS3**. This project presents a modern homepage layout with a navigation bar, hero banner, feature sections, statistics, sponsors, and footer.

## Live Preview Structure
The website includes:
- Header with navigation
- Hero/banner section
- Team image gallery
- Features section
- Facts/statistics cards
- Sponsors section
- Footer

## Technologies Used
- HTML5
- CSS3
- Google Fonts (Work Sans)

## Features
- Clean and modern landing page design
- Responsive layout for mobile, tablet, and desktop
- Reusable utility classes
- Grid and flexbox based layout
- Feature cards and stats section
- Sponsor logo showcase

## Responsive Design
This project includes media queries for:
- **Mobile devices**: up to 576px
- **Tablet devices**: 576px to 992px
- **Desktop devices**: above 992px

## How to Run the Project
1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

Or use VS Code with Live Server:
1. Open the folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Click **Open with Live Server**.

## Customization
You can easily customize:
- Text content in `index.html`
- Colors, spacing, and layout in `styles/architects.css`
- Images inside the `images/` folder

## Notes
- The design uses the **Work Sans** font from Google Fonts.
- The layout is built mainly with **Flexbox** and **CSS Grid**.
- This project is suitable for frontend practice and portfolio use.
